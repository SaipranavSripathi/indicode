IndiCode

The open source AI coding agent, built for India.

A fork of OpenCode with Sarvam AI and Krutrim AI as native, first-class providers — no plugin, no extra config.

terminal
$npm i -g indicode-ai@dev
$indicode
View on npm Star on GitHub

Everything OpenCode does. Plus India.

IndiCode inherits the full agent, tool, and provider system from OpenCode — and adds what was missing for Indian developers.

✓

Native Sarvam AI & Krutrim AI

Built into the core provider list from first run — not a plugin you have to find and install.

✓

Free to start

Comes with free models out of the box. Try the full agent loop before you need any API key.

✓

Cross-platform

One command installs on macOS and Windows via npm — no separate installers to chase down.

✓

Open source

MIT licensed, forked from OpenCode, fully auditable. Nothing hidden in the agent loop.

✓

Terminal-native

Keyboard-driven TUI, tool calling, MCP support, multi-session — the same agent core OpenCode ships.

✓

Any provider

Also works with OpenAI, Anthropic, and 70+ other providers via Models.dev, if you want them.

Indian LLM providers, built in

Set one environment variable and they show up in the model picker. No config file to hand-write.

Sarvam AI

sarvam-105b and sarvam-30b, optimized for Indian languages and context.

export SARVAM_API_KEY=...

Krutrim AI

Krutrim-1, Ola's foundation model, available the same way.

export KRUTRIM_API_KEY=...

Where this actually stands: IndiCode is a young project. It's published, it installs cleanly, and the agent loop works end to end — but it's still under the dev npm tag, not latest, while it gets more real-world use.
